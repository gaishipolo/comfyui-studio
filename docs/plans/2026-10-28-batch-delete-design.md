# 任务页 / 素材库批量删除 + 全选 — 设计

日期：2026-10-28 ｜ 状态：已实现

## 背景

- 素材库已有批量删除（勾选 ✓ → 顶部「删除 (N)」），但缺全选，逐张勾选成本高。
- 任务页完全没有批量删除，只能逐条删。

## 决策（用户拍板）

1. **两页都做**：任务页补「勾选 + 全选 + 批量删除」；素材库在现有批量删除上加「全选 / 清除选择」。
2. **全选范围 = 当前筛选结果**（素材库跟着搜索/标签/场景筛选走；任务页无筛选即全部任务）。
3. **执行方式 = 前端循环调现有单删接口**（方案 A），不加后端批量接口。
   理由：权限（本人/管理员）、级联删素材+磁盘、运行中拒删这些语义留在原地不复制第二份；
   逐条结果可如实汇总。N 条 N 个请求在本机量级下无所谓。

## 交互

### 任务页（TaskPanel.tsx）
- 表格首列勾选框，表头三态全选框（全不选 / 部分 / 全选）。
- 行点击仍展开详情；勾选框所在 `td` `stopPropagation`，不触发展开。
- **running 行勾选框禁用**（后端本来就拒删，勾了也是白勾）。
- 选中 ≥1 时顶部出「删除 (N)」「清除选择」。
- 3 秒轮询刷新时把已消失的 id 从选中集剔除，防止「删除 (N)」虚高。

### 素材库（AssetGallery.tsx）
- 筛选栏新增「全选 (N)」/「取消全选」（N=当前筛选可见数）与「清除选择」。
- 切换搜索/标签/场景筛选时清空选中，免得「删除 (N)」里混着看不见的图。
- 详情面板单删时若该素材在选中集里，同步摘掉。

## 删除流程

confirm 二次确认（写明不可逆 + 级联删素材和磁盘文件）→ 逐条删 → 汇总上报：
- 「N 条执行中已跳过」（后端 400，设计使然，与"删不动"分开归类）
- 「N 条删除失败」（如非本人提交，需管理员）
- 「N 条记录已删但磁盘文件残留」
→ 刷新列表 + 清空选中。

沿用既有约定：**文件删不掉绝不能让记录删除失败，且如实告知，不笼统说"已删除"**。
